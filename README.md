
# ToDo List App (Lab 2)

Консольное приложение на C++ для управления списком задач. Проект выполнен в рамках лабораторной работы по дисциплине «Промышленное программирование» с упором на автоматизацию разработки и методологию Git Flow.

## Технологический стек
* **Язык:** C++17
* **Система сборки:** CMake
* **Статический анализ:** Cppcheck

## Инструменты автоматизации (Git Hooks)
В репозитории настроены клиентские хуки для контроля качества и логирования:
* `pre-commit` - автоматически запускает проверку стиля кода через `cppcheck` перед каждым коммитом. При наличии ошибок блокирует коммит.
* `post-commit` - после каждого успешного коммита автоматически записывает метаданные (хеш, автор, дата, сообщение) в локальный файл `commit.log`.

## Сборка и запуск

Для сборки проекта вам понадобятся `cmake` и компилятор `g++` (или `clang`).

1. Создайте папку для сборки и перейдите в неё:
```bash
   mkdir build && cd build

```

2. Сгенерируйте файлы конфигурации:
```bash
cmake ..

```


3. Скомпилируйте проект:
```bash
make

```


4. Запустите приложение:
```bash
./todo_app

```



## Структура проекта

* `main.cpp` - исходный код приложения.
* `CMakeLists.txt` - скрипт сборки CMake.
* `.gitignore` - исключение временных файлов сборки (`/build/`) и локальных логов.
* `.git/hooks/` - скрипты автоматизации (настраиваются локально).
